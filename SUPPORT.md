# Support

Use GitHub Discussions for integration questions and GitHub Issues for reproducible defects in this repository.

Before asking for help, include:

- Node.js and npm versions
- ABP and .NET versions
- Backend topology: layered, single-layer, or microservice
- Whether the Auth Server is separate
- Browser console and network errors with secrets removed
- The relevant `dynamic-env.json` shape with private hosts anonymized

For ABP Framework product support, licensing, or generated-backend issues, use the official [ABP support channels](https://abp.io/support).
